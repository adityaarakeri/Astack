# astack

Meta-plugin with no skills of its own. Installing it installs every plugin in the Astack catalog as a dependency.

```text
/plugin install astack --marketplace adityaarakeri/Astack
```

Installs:

- `senior-agent-skills`: Makes a coding agent plan, test, and verify before shipping.
- `yolo`: Hands an agent one goal and stays out of the way.
- `context-relay-tdd`: Audits a repo, then fixes it one test-first item at a time, across context resets.
- `humanize-content`: Strips AI tells from text without adding new ones.
- `handcraft-html`: Builds HTML pages that do not read as generated.
- `frontend-engineering`: Senior frontend judgment for framework apps.
- `judgment-coach`: Coaches a decision instead of making it for you.

Generated by `scripts/build_catalog.py`; edit `catalog.json` instead.
